# Solmar Bay

An original 3D open-world crime game in the spirit of GTA 6: explore the coastal city of Solmar Bay on foot and by car, boat and motorcycle, run jobs for Vera Costa, outrun the Solmar PD under a five-star wanted system, and spend your earnings at Rico's Garage.

Play it at https://make.fun/bounty/gta6-01 — serve `game/` with any static server and open `game/index.html` in desktop Chrome. No network needed: three.js is vendored under `game/vendor/`.
